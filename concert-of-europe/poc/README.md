# Development-card production handoff

Start with [permanent-advances/PRODUCTION-SPEC.md](permanent-advances/PRODUCTION-SPEC.md).

It records the agreed rules, content requirements, minimal UI and verification work. The `handoff/` directory beside it contains the complete approved starting bonus matrix in readable and machine-readable forms.

Use the playable POC as a reference. Implement against the current main game, preserving its newer changes. The POC's original strengths and extra UI are superseded by the spec.
